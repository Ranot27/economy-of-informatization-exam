def fmt(value, digits=0):
    """Число в привычной записи: 7 950 или 50,07."""
    value = round(value, digits) + 0          # «+ 0» убирает минус у нуля
    text = f"{value:,.{digits}f}"
    return text.replace(",", " ").replace(".", ",").replace("-", "−")


def pct(value, digits=0):
    """Доля в процентах: 0.05 -> 5%."""
    return fmt(value * 100, digits) + "%"


def signed(value, digits=0):
    """Число со знаком: +30 или −30."""
    return ("+" if value > 0 else "") + fmt(value, digits)


def lower_first(text):
    """Первая буква — строчная: «Реклама» -> «реклама»."""
    return text[0].lower() + text[1:]

Экономическая постановка задачи¶

Проблема. Стартап «AI-Копирайтер» разработал сервис, который с помощью AI генерирует тексты для маркетинга, SEO и социальных сетей. Перед выходом на рынок нужно выбрать, как брать деньги с пользователей. Вариантов четыре: Freemium, подписка, динамическое и персонализированное ценообразование.

Актуальность. У цифрового продукта предельные затраты близки к нулю, поэтому цену нельзя вывести из себестоимости. Ее выбирают по ценности для пользователя и по метрикам: сколько пользователей платит, как долго они остаются и сколько стоит их привлечь.

Цель. Выбрать ценовую стратегию для вывода сервиса на рынок и обосновать выбор расчетами.

Задачи:

  1. посчитать ARPU, LTV и отношение LTV/CAC для каждой стратегии и канала привлечения;
  2. спрогнозировать прибыль за 3 года и посчитать NPV;
  3. проверить чувствительность к конверсии, оттоку (Churn) и CAC;
  4. выбрать стратегию, составить план внедрения и оценить риски.

2. Расчеты¶

2.1. Математическая модель¶

ARPU — средний доход с одного пользователя в месяц:

$$ARPU = P \cdot r$$

где $P$ — цена, $r$ — конверсия в платных пользователей.

LTV — доход с одного пользователя за весь срок его жизни в сервисе:

$$LTV = \frac{ARPU}{Churn} = ARPU \cdot T, \qquad T = \frac{1}{Churn}$$

Эффективность канала привлечения: $LTV / CAC$. По лекции бизнес устойчив при $LTV / CAC \ge 3$.

База пользователей: $N_t = N_{t-1} \cdot (1 + g_t)$, где $g_t$ — прирост года $t$ (100%, 50%, 20%).

Прибыль года:

$$П_t = ARPU \cdot N_t \cdot 12 - CAC \cdot (N_t - N_{t-1}) - C_{поддержание} \cdot 12$$

NPV: $NPV = -I_0 + \sum_{t=1}^{3} \dfrac{П_t}{(1+r)^t}$, где $I_0$ — затраты на разработку, $r$ = 12% годовых.

Откуда формулы. ARPU = Цена × Конверсия — критерии оценки задачи и лекция №4, раздел 2.2. LTV = ARPU / Churn и срок жизни 1 / Churn — условие и раздел 3.2. Порог LTV / CAC ≥ 3 — раздел 3.2. Прибыль и NPV — формула NPV подписки из раздела 3.4.

Почему эти методы. ARPU, LTV и LTV/CAC — основные метрики ценовых стратегий из лекции №4: они показывают, сколько приносит пользователь и окупается ли его привлечение. NPV нужен, чтобы сравнить стратегии по деньгам за 3 года с учетом стоимости денег во времени.

def price_of(strategy):
    """Цена стратегии; для диапазона цен — середина диапазона."""
    low, high = strategy["price"]
    return (low + high) / 2


def arpu_of(strategy):
    """ARPU: цена × конверсия, руб. в месяц на одного пользователя."""
    return price_of(strategy) * strategy["conversion"]


def ltv_of(strategy):
    """LTV: ARPU / Churn, руб. за весь срок жизни пользователя."""
    return arpu_of(strategy) / strategy["churn"]


def users_by_year():
    """База пользователей по годам, начиная с года 0."""
    users = [BASE["start_users"]]
    for growth in BASE["growth"]:
        users.append(users[-1] * (1 + growth))
    return users


def forecast(strategy, cac):
    """Таблица по годам: доход, затраты, прибыль и дисконтированная прибыль."""
    users = users_by_year()
    # Год 0: дохода еще нет, есть только затраты на разработку
    rows = [{"Год": 0, "Пользователи": users[0], "Новые": 0.0, "Доход": 0.0,
             "Привлечение": 0.0, "Поддержание": 0.0, "Разработка": BASE["development"]}]
    for year in range(1, len(users)):
        new_users = users[year] - users[year - 1]           # прирост базы за год
        rows.append({"Год": year, "Пользователи": users[year], "Новые": new_users,
                     "Доход": arpu_of(strategy) * users[year] * 12,
                     "Привлечение": cac * new_users,
                     "Поддержание": BASE["support"] * 12, "Разработка": 0.0})
    table = pd.DataFrame(rows).set_index("Год")
    table["Прибыль"] = (table["Доход"] - table["Привлечение"]
                        - table["Поддержание"] - table["Разработка"])
    table["Дисконт"] = 1 / (1 + BASE["rate"]) ** table.index    # коэффициент года
    table["Дисконтированная прибыль"] = table["Прибыль"] * table["Дисконт"]
    return table


def npv(table):
    """NPV: сумма дисконтированной прибыли по годам."""
    return table["Дисконтированная прибыль"].sum()

def variant(strategy, cac, parameter, factor):
    """LTV/CAC и NPV стратегии, если один параметр умножить на factor."""
    changed = dict(strategy)
    if parameter == "cac":
        cac = cac * factor
    else:
        changed[parameter] = strategy[parameter] * factor
    return ltv_of(changed) / cac, npv(forecast(changed, cac))

3.1. Интерпретация полученных данных¶

  • ARPU (задание 1). Больше всего приносит один пользователь при персонализированной стратегии (318 руб. в месяц) и при подписке (300 руб.). У динамической стратегии 187,5 руб., у Freemium всего 40 руб.: цена высокая (2 000 руб.), но платят только 2% пользователей.
  • LTV (задание 2). Порядок тот же: персонализированная — 7 950 руб., подписка — 6 000 руб., динамическая — 3 125 руб., Freemium — 500 руб. На LTV влияет не только ARPU, но и отток: при Churn 4% клиент остается в среднем 25 месяцев, при 8% — 12,5 месяца.
  • LTV/CAC (задание 3). Подписка и персонализированная стратегия проходят порог 3 во всех трех каналах, даже в самом дорогом — рекламе (4,0 и 5,3). Динамическая стратегия проходит порог в контент-маркетинге (3,9) и виральном росте, но не в рекламе (2,1). Freemium окупает привлечение только при виральном росте (5,0); в рекламе LTV/CAC равен 0,33 — пользователь стоит втрое дороже, чем приносит.
  • Прибыль (задание 4). Все четыре стратегии убыточны в каждом году. Причина одна: база мала. Даже в году 3 это 3 600 пользователей (0,72% рынка), и лучший доход — 13,74 млн руб. в год при затратах на поддержание 24 млн руб. в год. Убыток сокращается от года к году только у стратегий с высоким ARPU: у подписки с 17,60 до 11,52 млн руб.
  • NPV (задание 5). Персонализированная — −48,62 млн руб., подписка — −50,07, динамическая — −59,17, Freemium — −71,10. Из этих сумм 15 млн руб. — затраты на разработку, одинаковые для всех стратегий.

3.2. Сравнение с альтернативными вариантами¶

  • Чувствительность LTV/CAC (задание 6). LTV/CAC — это произведение и частное параметров, поэтому в процентах он меняется одинаково у всех стратегий: конверсия ±30% дает ±30%; рост Churn или CAC на 30% дает −23%, снижение на 30% дает +43%. Разница между стратегиями — в запасе до порога 3.
  • Чувствительность NPV (задание 6). Сильнее всего NPV зависит от конверсии: у подписки от −57,35 до −42,80 млн руб. CAC меняет NPV только на ±0,5 млн руб., потому что за 3 года привлекается всего 2 600 пользователей. Churn на NPV не влияет: по условию база пользователей задана моделью роста (допущение Д4). Ни в одном варианте NPV не становится положительным.
  • Устойчивость (задание 7). В худшем варианте LTV/CAC у персонализированной стратегии равен 6,96, у подписки — 5,25: обе остаются выше порога 3 при любом изменении. Динамическая при падении конверсии на 30% опускается до 2,73 — ниже порога. Freemium ниже порога всегда (от 0,44 до 0,89). Наиболее устойчива персонализированная стратегия, на втором месте подписка.
  • Числа и оценки из лекции (задание 8). По расчету первая — персонализированная стратегия, но ее отрыв от подписки мал: 1,46 млн руб. NPV, или 2,9%. При этом ее результат зависит от допущения Д1: она обгоняет подписку, только если средняя цена выше 2 500 руб., а в расчете принято 2 650 руб. У подписки все числа взяты из условия без допущений о цене. Динамическая стратегия сравнялась бы с подпиской по ARPU только при средней цене 2 000 руб., то есть если бы все платили верхнюю границу диапазона.

4. Выводы и рекомендации¶

4.1. Ключевые выводы¶

  1. По ARPU, LTV и NPV лидируют две стратегии с близкими результатами: персонализированная (ARPU 318 руб., LTV 7 950 руб., NPV −48,62 млн руб.) и подписка (300 руб., 6 000 руб., −50,07 млн руб.).
  2. Порог LTV/CAC ≥ 3 во всех каналах и при изменении параметров на ±30% выдерживают только эти две стратегии.
  3. Freemium при заданной конверсии 2% не подходит: LTV 500 руб. окупает привлечение только при виральном росте.
  4. При базе 1 000–3 600 пользователей убыточны все стратегии: доход не покрывает затраты на поддержание (24 млн руб. в год). Выбор ценовой стратегии уменьшает убыток, но не убирает его — нужен рост базы.
  5. Оптимальная стратегия для вывода на рынок — подписка (обоснование в разделе 4.2).

4.2. Практические рекомендации для «AI-Копирайтер»¶

Выбор стратегии (задание 8). Рекомендуется подписка за 1 500 руб. в месяц с пробным периодом. Причины:

  1. По расчету она почти не уступает лидеру: разница в NPV 2,9%, LTV/CAC выше порога во всех каналах.
  2. Ее числа надежнее: цена задана в условии одним числом. Результат персонализированной стратегии держится на допущении о средней цене.
  3. По матрице из лекции (раздел 7.1) у подписки низкая сложность и низкие затраты на внедрение и низкий риск для пользователей; она подходит для B2B и сервисов — это и есть аудитория «AI-Копирайтер» (маркетологи, SMM-специалисты, предприниматели). У персонализированной стратегии сложность и затраты «очень высокие», риск «высокий». Эти затраты в расчет NPV не входят, а они съели бы преимущество в 1,46 млн руб.
  4. Вывод лекции (раздел 8.1): подписка — самая устойчивая модель для B2B-сервисов при LTV/CAC > 3. Условие выполнено.

План внедрения (задание 9).

Коммуникационная стратегия:

  • главное сообщение — одна понятная цена и пробный период: «попробуйте бесплатно, потом 1 500 руб. в месяц»;
  • цена находится в нижней половине диапазона конкурентов (500–5 000 руб.), это стоит показывать в сравнении;
  • основные каналы — контент-маркетинг и SEO (LTV/CAC 7,5) и виральный рост (60): примеры сгенерированных текстов, кейсы клиентов, приглашения коллег. Реклама (LTV/CAC 4,0) — как дополнение, пока порог 3 выдерживается.

Дорожная карта:

  • год 1, выход на рынок: запуск подписки с пробным периодом, рост базы с 1 000 до 2 000 пользователей, проверка конверсии 20% и Churn 5% на реальных данных;
  • год 2, рост: база 3 000 пользователей, перенос бюджета в каналы с лучшим LTV/CAC, работа над удержанием;
  • год 3, зрелость: база 3 600 пользователей, ввод нескольких тарифов (многоуровневая подписка из лекции, раздел 3.3) как первый шаг к разным ценам для разных сегментов;
  • общий ориентир: MRR покрывает затраты на поддержание при базе 6 667 пользователей. Модель роста из условия дает 3 600, поэтому нужно либо расти быстрее, либо снижать затраты на поддержание.

Ключевые метрики для мониторинга (лекция, разделы 3.4 и 7.2):

  • MRR — сейчас 0,60 → 0,90 → 1,08 млн руб. по годам, цель — не ниже 2 млн руб.;
  • Churn — 5% в месяц, цель для B2B — ниже 5%;
  • LTV/CAC по каналам — 4,0 / 7,5 / 60, цель — не ниже 3;
  • окупаемость CAC — 5,0 / 2,7 / 0,3 месяца, цель — быстрее 12 месяцев;
  • конверсия из пробного периода — 20%; NRR (удержание выручки) — цель выше 120%, в условии данных для него нет.
